# spacy>=3.8 specifically (not 3.7.x): 3.7.x's backend (thinc 8.2.x / blis
# 0.7.x) was compiled before NumPy 2.0 existed and breaks at runtime against
# a NumPy 2.x install with "numpy.dtype size changed... binary

# until the model actually tries to load. 3.8's backend was built with
# proper NumPy 2.x ABI support.
#
# Models ARE pinned here as wheel URLs (tagged 3.8.0, to match spacy>=3.8) —
# NOT downloaded at runtime. Streamlit Cloud's running app process doesn't
# have write permission to the environment's site-packages (confirmed by a
# 'Permission denied' error attempting exactly that), so install-time is the
# only point models can actually be added.
